# RESONANCE · 音律核心

一个纯 HTML5 的单文件音游：内置多首程序化曲目，支持导入自己的音乐自动生成谱面。

### 🎮 [👉 点击这里直接在线游玩 👈](https://mi618ku.github.io/resonance-rhythm/)

---

### 🕹️ 操作说明

* **电脑端**：使用键盘 `D` `F` `J` `K` 或 `方向键` 击打，遇到长条需按住直到末端。
* **手机端**：直接在屏幕上点击对应的轨道。

### ✨ 核心特性

* **自动打谱**：支持导入本地音频（MP3/WAV等），基于起音检测和节拍网格自动生成谱面。
* **零外部资源**：纯单文件，打开即玩，无需下载任何图片或音频文件。
* **多语言 & 多主题**：内置中/英/日/韩四国语言，提供 5 套视觉主题自由切换。
* **跨平台**：自适应 PC 与移动端，完美适配不同屏幕尺寸。
