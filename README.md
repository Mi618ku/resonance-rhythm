# RESONANCE · 音律核心
# resonance-rhythm
一个纯 HTML5 的单文件音游：内置 9 首程序化曲目，支持导入自己的音乐自动生成谱面。


👉 **[点击这里直接在线游玩](https://mi618ku.github.io/resonance-rhythm/)**
### 🎮 操作说明
*   **电脑端**：使用键盘 `D` `F` `J` `K` 或 `方向键` 击打，长条需按住。
*   **手机端**：直接在屏幕上点击对应轨道。
*   ### ✨ 核心特性
*   **零外部资源**：纯单文件，打开即玩，无需下载任何图片音频。
*   **自动打谱**：支持导入本地音频（MP3/WAV等），基于起音检测和节拍网格自动生成谱面。
*   **多语言 & 多主题**：内置中英日韩，提供 5 套视觉主题。
